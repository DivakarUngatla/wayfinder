# Wayfinder
Wayfinder is a reference implementation for exploring, learning, and teaching AI Engineering through a realistic AI application.

Instead of isolated examples, Wayfinder evolves incrementally alongside the AI Engineering Fundamentals series. Each article introduces a new AI Engineering concept, and the repository implements it in a practical, production-oriented way.

The goal is not to build a production travel platform.

The goal is to demonstrate production AI engineering practices through a realistic application.
